# Datasets on KLC

The following datasets are stored directly on the Kellogg Linux Cluster under `/kellogg/data/`. Access requires a KLC account. See [How to Access KLC](user-guide/klc-accessing) if you do not yet have one.

Contact [rs@kellogg.northwestern.edu](mailto:rs@kellogg.northwestern.edu) to request access to a specific dataset.

```{note}
The datasets listed below are a selected subset with documentation on this site, not an exhaustive catalog. For an exhaustive list of datasets available to Kellogg researchers, see the [Kellogg Research Support Datasets page](https://www.kellogg.northwestern.edu/academics-research/research-support/dataset/).
```

| Dataset | Brief Description |
|---|---|
| [CME](../datasets/datasets/cme) | CME futures, options, and currency contracts (through 2007) |
| [Comscore](../datasets/datasets/comscore) | Historical clickstream, media measurement, and audience data; raw files on KLC and AWS Athena tables |
| [Cotality (formerly CoreLogic)](../datasets/datasets/cotality) | Real property data for 147M+ US properties: assessments, transfers, mortgages, MLS listings |
| [EDGAR](../datasets/datasets/edgar) | All SEC filings in raw format, suitable for large-scale text analysis and variable extraction |
| [Nielsen Marketing Data](../datasets/datasets/nielsen-marketing-data) | Consumer Panel, Retail Scanner, and Ad Intel |
| [PATSTAT](../datasets/datasets/patstat) | Worldwide patent database prepared by the European Patent Office |
